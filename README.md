# Порядок — сайт

Посадкова сторінка сервісу **«Порядок»**: чек-листи зміни з фотозвітом
у Telegram для мереж точок.

Сам продукт: [@poriadok_app_bot](https://t.me/poriadok_app_bot)

## Що тут лежить

Один файл — `index.html`. Усе всередині: стилі, розмітка, логіка й навіть
шрифт. Ні збірки, ні залежностей, ні кроку встановлення.

Так зроблено навмисно. Сторінку треба відкрити, показати й іноді швидко
поправити слово перед зустріччю — а не збирати проєкт заради коми.

Шрифт — [Fixel](https://fixel.macpaw.com) від MacPaw, ліцензія SIL OFL.
Вшитий у файл, бо GitHub Pages не має де його взяти.

## Як правити

Відкрити `index.html` у редакторі, змінити текст, зберегти, надіслати в
`main`. За хвилину-дві сторінка оновиться сама.

Джерело сторінки живе в основному репозиторії продукту, у теці `landing/`.
Сюди вона потрапляє копією разом із вшитим шрифтом.
